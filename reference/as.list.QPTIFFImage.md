# Convert a QPTIFFImage to a named list of 2-D channel matrices

Convert a QPTIFFImage to a named list of 2-D channel matrices

## Usage

``` r
# S3 method for class 'QPTIFFImage'
as.list(x, ...)
```

## Arguments

- x:

  A `QPTIFFImage`.

- ...:

  Unused.

## Value

A named list of 2-D matrices, one per channel.
